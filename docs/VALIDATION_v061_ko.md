# Pixelwright v0.6.1 회귀 수정 검증

검증일: **2026-10-21**. v0.6.0 검토에서 재현한 오류 5건과 anchor 보정 문제를 수정했습니다. 원본 이미지와 동봉 예제는 바꾸지 않았고, 기존 QA 허용치도 유지했습니다.

## 수정과 회귀 테스트

| 문제 | 수정 | 회귀 확인 |
| --- | --- | --- |
| 빌드 도중 다른 작업이 만든 출력 파일을 실패 정리가 삭제함 | 독점 생성에 성공한 파일만 정리 대상으로 기록하고, 자기 쓰기가 실패한 부분 파일만 삭제 | 외부 파일 보존, 앞서 만든 자기 출력 정리, 부분 쓰기 실패 |
| 부모 부위가 완전히 가려지면 자식 연결 검사를 건너뜀 | 고정·rigid·bone 부모의 기준 도트를 현재 자세로 옮기고 실제 앞 부위의 가림과 겹치는 위치에서 연결 검사 | 가려진 부모에 연결된 정상 자식과 떨어진 자식 구분 |
| 3D 길이·허용치에 NaN/Infinity를 넣으면 늘어난 뼈가 통과함 | 기준 길이는 유한한 양수, 허용치는 유한한 0 이상 숫자로 제한 | 비수치·bool·0·음수·숫자 오버플로와 다시 투영한 늘어난 무기 거부, 정상 값·허용치 0 통과 |
| 정상 부위의 가운데 여러 칸이 가려지면 조각 분리 REVIEW 발생 | 기존 한 칸 가림 연결을 유지하고, 추가 연결은 변환된 기준 도트와 앞 부위가 겹치는 영역으로 제한 | 정상 중앙 가림 통과, 무관한 앞 부위를 우회한 연결과 실제 조각 분리는 허용하지 않음 |
| GIF 요청 시간과 실제 저장 시간이 다른데 PASS로 기록함 | 최소 10ms, 10ms 단위 반올림을 명시하고 저장한 GIF를 다시 열어 시간·반복 정보를 확인 | 1·9·15·16·111ms, 반복 유무, 동일 프레임 병합, 잘못 저장된 시간·반복 정보 |
| 이미 정합된 anchor를 bbox에 다시 맞춰 확대하면 머리 비율 검사 실패 | 기존 자세 검사를 통과한 원본은 위치와 배율 1.0을 유지하고, 미정합 원본에는 기존 균일 보정 적용 | bbox가 한 칸 달라도 정합 상태 유지, 미정합 원본 보정 경로와 원본 바이트 보존 |

새 회귀 테스트는 **23개**입니다. 단위 테스트는 작은 도트·골격 입력과 정상 대조군을 사용하며 Blender 설치 없이 실행됩니다.

GIF의 `durations_ms`·`total_ms`는 요청한 게임용 시간을 그대로 유지합니다. GIF로 정확히 표현할 수 없는 시간은 `GIF_TIMING_QUANTIZED` REVIEW이고 종료 코드는 `2`입니다. `preview_timing.art`·`preview_timing.rig`에 요청 시간, GIF에 배정한 시간, 실제 프레임별 시간·반복·병합 정보를 따로 기록합니다. 저장 결과가 배정한 시간이나 반복 정보와 다르면 `GIF_PREVIEW_METADATA_MISMATCH` FAIL입니다. 기존 100·110ms 예제는 그대로 PASS하며 GIF 바이트도 유지됩니다.

## 전체 테스트와 설치 검증

Windows에서 Pillow 12.3.0·NumPy 2.5.4로 실행했습니다.

| 환경 | 전체 테스트 | 결과 |
| --- | ---: | --- |
| Python 3.12.10 | 232개 | 230개 통과, 심볼릭 링크 권한이 필요한 2개 건너뜀 |
| Python 3.14.7 | 232개 | 230개 통과, 심볼릭 링크 권한이 필요한 2개 건너뜀 |

설치 ZIP과 개발 키트의 파일 목록·해시를 검증하고, ZIP을 별도 폴더에 풀어 CLI를 실행했습니다. 기존 팔레트·레이어·정사각형 격자·스프라이트 검증에 더해, 설치본에서도 9ms 요청이 보존되고 일반·리그 GIF가 실제 10ms 이상으로 저장되며 REVIEW를 반환하는지 확인합니다. 입력 해시 보존과 잘못된 관절의 실패 검사도 유지합니다.

```sh
python -m unittest discover -s pixelwright/tests -v
python tools/package_skill.py --out-dir dist
python tools/package_skill.py --verify dist/pixelwright-v0.6.1.zip
python tools/verify_release.py --archive dist/pixelwright-v0.6.1.zip --out-dir .work/release-v061-check
```

[CI](../.github/workflows/ci.yml)는 Ubuntu·Windows 각각 Python 3.12·3.14에서 전체 테스트와 설치 ZIP 검증을 실행합니다. 원격 실행 결과는 [Actions](https://github.com/jungducknam/pixelwright/actions)에서 커밋별로 확인할 수 있습니다.

## 실제 Blender 재검증

공식 SHA-256을 확인한 Blender **5.2.2 LTS**로 18개 자세, 38개 메시, 72개 PNG를 다시 생성했습니다. 골격 길이·독립 투영·관절·메시 연결 검사가 모두 PASS했고, 보간된 타임라인 69프레임도 PASS했습니다. 타임라인의 최대 뼈 길이 오차는 약 `5.07e-7m`, 공유 관절 간격은 약 `5.07e-7m`입니다.

기존 실제 렌더를 새 작업 폴더에 복사해 anchor부터 시트 검사까지 재실행했습니다. 이전에는 bbox를 맞추며 약 1.013배 확대해 머리 ROI 비율이 약 1.226으로 실패했지만, 수정 후에는 배율 **1.0**, 머리 ROI 비율 **1.111**로 자세·픽셀 QA가 PASS했습니다. 허용치 변경 없이 원본 파일 해시도 보존했습니다. 이 결과는 기술 검증이며 그림의 미적 완성도 평가는 포함하지 않습니다. 외부 이미지 생성 API의 유료 호출은 실행하지 않았습니다.

## 별도로 재현한 기존 경계

동일한 프레임을 `frame_ms=60000`으로 11회 반복하면 Pillow가 660초의 단일 hold로 합치며 GIF의 단일 지연 상한 655.35초를 넘겨 저장 오류가 발생합니다. 이 장시간 동일 프레임 병합은 이번 수정 전에도 존재한 한계이며, 위 여섯 수정의 해결 범위에 포함하지 않았습니다.
