# 게임 계약 검증 기록

검증일: **2026-11-03**. Linux 컨테이너에서 Python 3.12.3·3.14.6(Pillow 12.3.0)과 Python 3.12.3(Pillow 13.0.0)으로 단위 테스트 258개가 모두 통과했습니다. 그중 게임 계약 테스트는 19개입니다. 패키지 검증과 설치 ZIP 실행 검증도 통과했습니다. Windows는 CI 결과를 따로 확인해야 합니다.

## 무엇을 더했나

- [`scripts/pixel_game.py`](../pixelwright/scripts/pixel_game.py): 게임 하나가 공유하는 기본 해상도, 1× 픽셀 크기, 팔레트, 에셋 종류별 크기, 스타일 결정(시점, 광원, 음영, 외곽선, 디더링, 안티앨리어싱, 폰트, 애니메이션 속도, 회전, 이펙트 혼합, 엔진)을 `game.json`으로 받아 다섯 가지 명령을 제공합니다.
  - `brief`: 그림을 그리기 전에 따를 스타일 지침을 출력합니다.
  - `viewport`: 창 크기별 정수 배율과 여백을 계산합니다.
  - `asset`: 1× 에셋을 검사합니다.
  - `intake`: 새 에셋을 기준 에셋 옆에 1×로 놓고 비교합니다.
  - `screen`: 무손실 게임 스크린샷을 검사합니다.
- [`references/game.md`](../pixelwright/references/game.md), [`references/engines.md`](../pixelwright/references/engines.md): 계약 항목과 판정 코드, 엔진별 설정(Unity, Godot 4, Phaser 3, PixiJS, 웹 캔버스, LÖVE, GameMaker)을 설명합니다. 엔진 설정 이름은 버전마다 다를 수 있어 사용하는 버전에서 확인하라고 적었습니다.
- `SKILL.md`: 게임용 작업이면 스타일 결정을 먼저 모아 계약을 만들고, 브리프를 모든 에셋과 생성 프롬프트에 따르도록 했습니다. 게임에 넣을 때의 규칙 8가지를 넣었습니다.
- [`examples/game/`](../pixelwright/examples/game/): 384×216, 16×16 타일, 11색 팔레트의 예제 계약과 1× 타일·캐릭터(행렬 원본과 빌드 결과)입니다.

## 확인한 판정

예제의 타일과 캐릭터를 바탕으로 한 가지씩 바꿔 검사했습니다. 화면은 384×216을 5배로 키워 2000×1100 창에 가운데 놓았습니다(좌우 40, 위아래 10 여백).

## 한계

- 점 크기는 가로·세로 각각 색 경계 간격의 최대공약수입니다. 디테일이 모두 2칸 단위인 1× 에셋도 2로 측정될 수 있어, 축마다 경계가 8개 미만이면 FAIL이 아니라 REVIEW로 둡니다. 부분 확대(`COARSE_REGION`)도 검토 대상이지 자동 불합격이 아닙니다.
- 광원 방향, 음영의 질, 분위기는 측정하지 않습니다. 브리프로 전달하고 `side_by_side.png`를 보며 사람이 판단합니다.
- 스크린샷은 엔진의 무손실 캡처여야 합니다. 색 관리나 감마 변환이 들어간 캡처는 팔레트 판정을 흔듭니다.
- 실제 엔진에서 캡처한 화면으로는 아직 검사하지 않았습니다. 위 화면은 모두 같은 규칙으로 합성한 대역입니다.

## 검토 후 수정

PR 전에 따로 검토해 재현한 9건을 고치고 각각 회귀 테스트를 넣었습니다. 추가한 테스트는 수정 전 코드에서 실패하고 수정 후 통과합니다.

- 화면보다 큰 배경·타일셋이 범주 크기와 맞아도 항상 실패하던 문제: 범주가 있으면 범주 규칙만 적용하고, 범주 없이 크면 검토로 둡니다.
- 경계가 적은 단순 1× 무늬(4×4 체크, 2칸 외곽선 사각형)를 확대 에셋으로 단정해 실패시키던 문제: 축마다 경계 8개 이상일 때만 실패입니다. 수용 검사의 `PIXEL_SIZE_DIFFERS`도 두 측정이 모두 확실할 때만 실패입니다.
- 부분 확대 검사가 8칸 간격 창만 봐서, 정렬되지 않은 위치나 오른쪽·아래 가장자리의 2배 요소를 놓치던 문제: 모든 창 위치를 벡터 연산으로 검사합니다.
- 가로·세로 점 크기를 하나로 합쳐 한 방향으로만 늘린 에셋을 놓치던 문제: 축별로 잽니다.
- 디더링 판정이 겹친 창을 세어 작은 체크 한 조각에도 걸리던 문제: 체크 무늬에 속한 픽셀 16개 이상으로 바꿨습니다.
- `--scale 0`이 자동 배율로 처리되던 문제, 문자열 외곽선 색·참조 목록과 숫자 팔레트 항목이 잘못된 오류를 내던 문제, `font.file` 경로를 검사하지 않던 문제, SKILL.md가 `asset` 명령이 만들지 않는 파일을 언급하던 문제를 고쳤습니다.
