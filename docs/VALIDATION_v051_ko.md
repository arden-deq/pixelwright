# Pixelwright v0.5.1 격자 미리보기 수정

검증일: **2026-10-15**. 검사 대상 작품의 픽셀은 바꾸지 않고, 잘못된 격자 미리보기를 수정했습니다.

320×224 논리 셀을 4배로 렌더링한 1280×896 이미지에서 이전 검사기는 세로선을 2칸마다, 가로선을 1칸마다 표시했습니다. 그 결과 실제 4×4px 셀 위에 **8×4px 직사각형 격자**가 나타났습니다. 이미지 표시 배율 문제가 아니라 진단 이미지 생성 버그였습니다.

현재 검사기는 양 축에서 모든 셀 경계를 표시합니다. 오른쪽·아래쪽 외곽 경계는 캔버스 밖에 두며, 마지막 픽셀로 옮겨 끝 셀을 좁히지 않습니다. `report.json`의 `grid_preview`에 선 생략 여부와 양 축 간격을 기록합니다. 촘촘한 격자는 같은 배율로 확대한 부분 이미지로도 확인합니다.

회귀 테스트는 가로형 320×224·세로형 224×320의 4배 격자와 512×300의 2배 격자에서 모든 선의 위치, 개수, 간격, 마지막 셀 내부를 검사합니다. 저장된 실제 QA 오버레이도 별도로 검사합니다. 이 테스트들은 이전 구현에서 실패하고 수정 후 통과했습니다.

Python **3.12.10**과 **3.14.7**, Pillow **12.3.0**, NumPy **2.5.4**에서 각각 전체 **140개 테스트 중 138개 통과, 2개 건너뜀**을 확인했습니다. 두 건은 Windows 심볼릭 링크 생성 권한이 필요한 기존 테스트입니다. Skill 형식 검사와 `git diff --check`도 통과했습니다.

사용자가 지적한 성문·기사 작품의 수정된 투명 격자 레이어를 독립 측정했습니다. 세로선 320개는 x=0,4,…,1276, 가로선 224개는 y=0,4,…,892에 있으며 **모든 선 간격이 4×4px**입니다. 작품은 320×224 원본의 정확한 4배 최근접 확대이고, SHA-256은 수정 전후 동일합니다.

```text
7afa6fd5dfcc2073bba98539bdc04f288a759084f016e438ef0ddcbc8f7d4bdd
```

설치 ZIP 검증에도 동봉 레이어 장면의 실제 `grid_lines.png`에서 양 축의 모든 4px 경계를 검사하는 절차를 추가했습니다. 기존 팔레트 추출·재매핑·램프 재사용, 원본 해시 보존, 실패 시 승인 PNG 미출력 검사도 유지합니다.

README에서 연결한 헤더와 레이어 예제의 파생 격자 PNG 14개도 현재 검사기로 다시 생성했습니다. 정상인 기사 격자와 한·영 비교 그림은 유지했습니다. 전체 9개 격자의 선 간격·경계를 검증했고, 원본 그림·논리 행렬·프로필·기존 QA 보고서 등을 포함한 75개 파일의 해시는 모두 보존됐습니다. 헤더 검증 기록에는 현재 미리보기 간격과 수정 이력을 함께 남겼습니다.

```sh
python -m unittest discover -s pixelwright/tests
python tools/package_skill.py --out-dir dist
python tools/package_skill.py --verify dist/pixelwright-v0.5.1.zip
python tools/verify_release.py --archive dist/pixelwright-v0.5.1.zip --out-dir runs/release-v051-check-v1
```

실행마다 새 출력 폴더를 사용합니다. v0.5.0 팔레트 기능의 상세 검증은 [기존 기록](VALIDATION_v050_ko.md)에 남겨 둡니다. 이전 버전에서 만든 격자 미리보기는 현재 검사기로 다시 생성해야 합니다.
