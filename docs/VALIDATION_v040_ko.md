# Pixelwright v0.4.0 레이어 검증 기록

검증일: **2026-10-14**. Windows의 Python 3.14.7, Pillow 12.3.0, NumPy 2.5.4를 갖춘 격리 환경에서 실행했습니다. 패키지의 NumPy 최소 의존성은 Python 3.12 이상을 요구합니다. 실제 Claude 계정 설치·업로드는 이 검증에 포함하지 않았습니다.

## 테스트

전체 102개 테스트 실행은 `OK (skipped=1)`입니다. 기존 67개와 신규 레이어 35개를 포함하며, Windows에서 심볼릭 링크 생성 권한이 없어 경로 이탈 symlink 테스트 1개만 건너뛰었습니다. Ubuntu CI에서는 이 테스트를 실행할 수 있습니다.

신규 테스트는 겹침 순서·투명 구멍·정수 좌표·두 배율·숨김 레이어·팔레트 합집합·불투명 최종 배경·부분 알파·정확한 숨은 RGB·해시 고정·원본 보존·출력 충돌·경로 이탈·자원 상한을 확인합니다. 실행 중 목록·프로필이 바뀌는 세 시점도 재현하여 승인 PNG를 남기지 않는지 검사했습니다.

## 동봉 예제

동봉 [레이어 목록](../pixelwright/examples/layered-scene/scene.json)은 검증된 기존 기사와 장비를 한 레이어로 유지하고, 직접 작성한 배경·랜턴 아이템·문구를 별도로 합성합니다. 워크플로를 보여 주는 예제이며 새로운 미적 품질 보장을 주장하지 않습니다.

| 입력 | 논리 크기 | 위치 | 엄격한 단색 셀 | 결과 |
| --- | --- | --- | ---: | --- |
| 배경 | 320×224 | (0, 0) | 71,680 | PASS |
| 기사와 장비 | 128×192 | (176, 16) | 24,576 | PASS |
| 아이템 | 32×32 | (56, 156) | 1,024 | PASS |
| 문구 | 128×24 | (16, 24) | 3,072 | PASS |
| 최종 합성 | 320×224 → 1280×896 | 원점 (0, 0), 4배 | 71,680 | PASS |

공통 허용 팔레트는 가시 색상 31개와 투명색을 포함한 32개 RGBA 값입니다. 불투명 최종 PNG의 실제 가시 색상은 31개입니다. 입력과 최종 검사에서 불균일 셀·반투명 샘플·팔레트 밖 샘플은 모두 0개입니다.

[실제 레이어별 결과](examples/layered-scene/layers.json), [최종 보고서](examples/layered-scene/final-report.json), [원본 결과](examples/layered-scene/rendered.png), [실제 격자 미리보기](examples/layered-scene/grid_overlay.png)를 보관했습니다. 공개 보고서의 출처 경로는 저장소 루트 기준으로 정리했고 해당 PNG·프로필과 해시가 일치합니다. 이 예제의 조밀한 격자는 수직 참고선을 두 셀마다 표시하지만 모든 4×4 셀을 검사합니다.

## 독립적인 Skill 사용

구현 결론을 제공하지 않은 별도 에이전트가 Skill만 읽고 40×24 논리 캔버스·4배·최대 가시 8색의 배경·랜턴·단색 문구 장면을 만들었습니다. 첫 합성은 8색, 문구를 옮기고 랜턴을 숨긴 합성은 4색이며 둘 다 PASS입니다. 숨긴 랜턴도 개별 QA를 통과했습니다. 수정 전 46개 파일이 이후에도 바이트까지 동일했습니다.

별도로 한 물리 샘플을 바꾼 입력은 불균일 셀 1개와 종료 코드 2를 기록했습니다. 실행 자료는 개인 작업 경로를 포함해 `.work/`에 보관하고 배포에서 제외했습니다.

## 설치 패키지 실행

소스 트리에 의존하지 않고 설치 ZIP만 풀어 랜턴 생성·검사와 동봉 레이어 합성을 실행했습니다. 랜턴 256셀과 최종 장면 71,680셀이 PASS였습니다. 별도 복사본의 숨긴 문구 레이어에 한 샘플을 바꾸자 FAIL, `final.status: not_composed`, 승인 PNG 없음으로 종료했습니다. 원본 설치 에셋은 보존됐습니다.

```sh
python -m unittest discover -s pixelwright/tests -v
python tools/package_skill.py --out-dir dist
python tools/verify_release.py --archive dist/pixelwright-v0.4.0.zip --out-dir runs/release-v040-check-v1
```

Skill 형식 검사도 통과했습니다. [CI](../.github/workflows/ci.yml)는 Ubuntu와 Windows 각각 Python 3.12·3.14에서 테스트·패키징·설치 ZIP 실행을 검증하도록 구성했습니다. 기술 PASS와 별도로 개별 작화 및 합성본의 접점·가림·문구 가독성을 검토합니다.
